# Java Lab Assignments – BCS351

**Student Roll Number:** BCS2025477  
**Course:** Introduction to Programming Using Java Lab  
**Institution:** Invertis University, Bareilly  
**Editor specified for the lab:** Visual Studio Code (VS Code)

This repository contains all 15 assignments from the supplied BCS351 lab assignment sheet. Each assignment has one `README.md`; each question has its own folder containing `Main.java` and `output.png`.

## Structure

- `Assignment1/` through `Assignment15/`
  - `Question1/`, `Question2/`, etc.
    - `Main.java`
    - `output.png`
  - `README.md`

## Compile and run

Open a question folder in VS Code with a JDK installed, then run:

```bash
javac Main.java
java Main
```

The programs use the fixed values specified in the lab sheet, so no runtime input is required.

## Lab file

The consolidated lab-file PDF is supplied separately with a code-view image followed by the corresponding output image for every question. The included editor/terminal images are formatted illustrations, not direct screenshots captured from a running VS Code application.
